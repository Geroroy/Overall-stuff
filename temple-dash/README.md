# Temple Dash — 인형 추격전

브라우저에서 바로 실행되는 3D 엔드리스 러너입니다. 유적 위의 돌길을 달리며
모퉁이에서 회전하고, 장애물을 점프/슬라이드로 피하고, 코인을 모읍니다.
뒤에서는 사진 속 인형 세 마리(회색 고릴라, 주황 원숭이, 초록잠옷 원숭이)가
쫓아옵니다. 장애물에 걸려 휘청이면 바짝 따라붙고, 그 상태에서 한 번 더
걸리면 잡힙니다.

## 실행

`temple-dash/index.html`을 브라우저에서 열면 됩니다(별도 빌드 없음).
Three.js는 cdnjs에서 불러오므로 인터넷 연결이 필요합니다.

```
cd temple-dash && python3 -m http.server 8080   # 또는 파일을 더블클릭
```

## 조작

| 입력 | 동작 |
|---|---|
| ← → / A D | 모퉁이에서 회전, 평소에는 좌·우 레인 이동 |
| ↑ / W / Space | 점프 (통나무, 뿌리, 그루터기, 구덩이) |
| ↓ / S | 슬라이드 (낮은 돌 들보 아래) |
| 모바일 | 스와이프 ← → ↑ ↓, 탭으로 시작 |

## 규칙

- 거리 1 m = 1점, 코인 1개 = 10점. 시간이 지날수록 빨라집니다.
- 그루터기(한 레인)·뿌리(전체 폭)에 걸리면 **휘청** → 추격 거리가 줄어듭니다. 시간이 지나면 다시 벌어집니다.
- 추격 거리가 가까운 상태에서 또 휘청이면 **잡힘**.
- 통나무·나무·돌 들보에 정면으로 부딪히거나, 구덩이·모퉁이 끝에서 떨어지면 게임 오버.
- 최고 점수는 브라우저 `localStorage`에 저장됩니다.

## 저작권 관련

원작의 에셋(모델, 텍스처, 음악, 캐릭터, 이름)은 전혀 사용하지 않았습니다.
길·나무·장애물·주인공은 모두 코드로 생성한 원본 형상과 캔버스 텍스처이며,
추격자는 원작의 악마 원숭이 대신 `assets/`의 인형 사진을 바탕으로 만든
단순 3D 모델입니다. 효과음은 Web Audio로 합성합니다. 제목도 원작 상표와
다르게 지었습니다.

## 파일

- `index.html` — 게임 전체(렌더링, 트랙 생성, 충돌, 입력, UI)
- `assets/cast-*.jpg|png` — 시작 화면에 쓰는 인형 사진(EXIF 제거, 축소)
